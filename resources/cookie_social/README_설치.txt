COOKIE SERVER - F9 세로형 모션 HUD + 동의 기반 업기
버전: V1.0.0
==================================================

[설치]
1. 이 ZIP의 cookie_social 폴더를 resources/[cookie]/ 안에 통째로 넣으세요.
2. scully_emotemenu가 설치·실행되고 있는지 확인하세요.
3. server.cfg에서 ensure [cookie]를 이미 쓰고 있다면 추가 ensure 없이 자동 시작될 수 있습니다.
   자동 시작되지 않는다면 scully_emotemenu 시작 이후에 ensure cookie_social을 추가하세요.
4. server.cfg에서 기존 설정은 유지하세요:
   setr scully_emotemenu:menuKeybind ""
   ※ 기존 이모트 F5/F9 자동 바인딩을 제거하기 위한 설정. 기존 개인 키 바인딩은 ESC > 설정 > 키 설정 > FiveM에서 해제 필요.
5. qbx_vehicleradio의 F9 키 매핑이 남았다면 FiveM 키 설정에서 해제하세요.
   차량 라디오 리소스 자체는 삭제하지 않아도 됩니다.
6. 서버 전체 재시작. F9 또는 /모션 명령으로 열기.

[사용]
F9 : 세로 모션 HUD
/모션 : 모션 HUD 열기
/업기 또는 /carry : 2.5m 안의 시민에게 업기 요청
/업기취소 또는 /carryoff : 업기 중단
/모션취소 : 사용 중인 모션 취소

[화면]
오른쪽에 길게 열리는 세로형 쿠키 골드/브라운 모션 HUD
추천 / 춤 / 생활 / 걸음걸이 / 연기 / 인사 탭
검색, 전체 모션 라이브러리(Scully 연결), 사람 업기/취소
기존 Scully 모션 목록과 소품 모션은 '전체 모션 라이브러리'에서 접근

[업기]
상대방 동의가 있어야 업기 진행
서버에서 거리·중복 요청·요청 만료 검사
사망/차량 탑승/접속 종료 시 자동 취소
타 리소스의 업기 시스템과 동시에 실행하지 마세요.

[주의]
새 리소스를 추가하는 방식입니다. cookie_admin / cookie_factionmenu / cookie_hud 파일은 변경하지 않습니다.
일부 scully 모션 명령은 서버에 설치된 모션 목록에 따라 다를 수 있습니다.
기존 F9가 라디오나 이모트 메뉴에 저장된 경우 개인 키 설정에서 변경하세요.
실제 FiveM 서버의 멀티플레이 애니메이션 동기화 테스트는 수행하지 못했습니다.
