COOKIE DAISO F5 + WEAPON PARTS V1.0.0
======================================

기준
- 사용자가 제공한 resources(2).zip
- 이전 COOKIE_PHARMACY_F5_MANUAL_ACCOUNT_V1.0.0 내용을 포함/보존

다이소 인식
- 팩션 이름에 "다이소"가 들어가면 다이소 전용 F5가 적용됩니다.
- 별도 faction type은 추가하지 않습니다.
- 필요하면 config.lua의 Config.DaisoFactionIds에 팩션 ID를 넣을 수 있습니다.

다이소 파츠 5종
- daiso_suppressor : 소음기
- daiso_flashlight : 손전등
- daiso_scope : 조준경
- daiso_extended_clip : 확장탄창
- daiso_grip : 그립

사용법
1. 플레이어가 파츠 아이템을 보유합니다.
2. 장착할 총기를 손에 듭니다.
3. 인벤토리에서 파츠를 사용합니다.
4. ox_inventory가 해당 총기에 맞는 GTA 컴포넌트를 찾아 2.5초 후 장착합니다.
5. 호환되지 않는 총기면 아이템은 소모되지 않고 오류 안내가 표시됩니다.

F5 다이소 전용 메뉴
- 판매 파츠 5종 / 코드 안내
- 팩션 관리자가 설정한 판매 품목·가격 확인
- 판매·정산 계산기 (자동 정산 없음)
- 공동계좌 현황
- 공동계좌 수동 입금
- 공동계좌 수동 출금 (간부/대표 권한)
- 입출금 로그

NPC 구매 권한
- 기존 팩션 NPC 권한을 수정하지 않습니다.
- 시민이 NPC에서 직접 구매할 수 없고 팩션원이 매입 후 시민에게 판매하는 기존 구조 그대로입니다.

파츠 제거
- 다이소 전용 제거 기능은 추가하지 않았습니다.
- ox_inventory 자체의 기존 무기 파츠 제거 기능은 코어 기능이므로 그대로 유지됩니다.

F3 판매 목록 등록 예시
- 아이템 코드에 위 daiso_* 코드를 입력해 다이소 팩션 판매 목록/NPC에 등록하세요.
- 가격, 설명은 기존 팩션 관리 기능에서 자유롭게 설정합니다.

설치
- 서버 종료
- ZIP의 [cookie], [ox] 폴더를 resources에 경로 그대로 덮어쓰기
- 서버 시작
- ox_inventory와 cookie_factionmenu가 정상 시작되는지 확인

별도 SQL은 필요하지 않습니다.
