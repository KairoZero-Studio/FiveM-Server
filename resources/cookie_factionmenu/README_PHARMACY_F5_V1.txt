COOKIE 약국 전용 F5 V1.0.0
==========================

기준
- 사용자가 제공한 resources(2).zip 기준
- 약국 전용 faction type을 추가하지 않음
- 시민의 팩션 NPC 구매 권한은 변경하지 않음
- 직급/부서는 기존 F3 팩션 관리에서 자유롭게 구성

약국 자동 인식
- 기본: 팩션 이름에 '약국'이 들어가면 약국 전용 F5 적용
- 예: 약국 / 쿠키약국 / 중앙약국
- 이름에 '약국'이 없는 경우 config.lua의 Config.PharmacyFactionIds에 팩션 ID를 추가하면 적용 가능

F5 기능
1) 판매 · 정산 계산기
- 상품명
- 개당 매입 단가
- 판매 수량
- 목표 마진율
- 개당 판매가 직접 입력 (0이면 목표 마진율로 자동 계산)
- 공동계좌 적립률

계산 결과
- 권장 판매 단가 (100원 단위 올림)
- 실제 적용 판매 단가
- 총 매입액
- 총 판매액
- 예상 손익
- 매출 기준 공동계좌 입금액
- 이익 기준 공동계좌 입금액

※ 계산만 수행합니다. 공동계좌에는 자동 입금되지 않습니다.

2) 공동계좌 현황
- 현재 팩션 공동계좌(cookie_faction.budget) 잔액
- 내 은행 잔액
- 최근 약국 수동 입출금 30건

3) 공동계좌 입금
- 약국 팩션원 누구나 본인 은행 계좌에서 공동계좌로 수동 입금
- 메모 필수
- cookie_faction_budget_log에 기록

4) 공동계좌 출금
- F3 직급 설정에서 간부(isOfficer) 또는 대표(isLeader)로 지정된 직급만 사용 가능
- 공동계좌 -> 본인 은행 계좌
- 출금 사유 필수
- cookie_faction_budget_log에 기록

설치
- 서버 종료
- 기존 resources/[cookie]/cookie_factionmenu 백업
- 본 압축파일의 [cookie]/cookie_factionmenu 폴더로 교체
- 별도 SQL 필요 없음
- 서버 시작

변경하지 않은 것
- 팩션 NPC 구매 권한
- 팩션 상점 판매 방식
- 약국/사설 팩션 type
- 직급/부서 구조
- 시민 판매 시스템
- 다른 팩션 F5
