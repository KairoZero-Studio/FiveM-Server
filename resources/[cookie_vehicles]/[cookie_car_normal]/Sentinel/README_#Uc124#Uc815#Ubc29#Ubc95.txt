쿠키서버 - Sentinel XS 일반차 핸들링 패치

대상 모델:
sentinel

표시명:
센티널 XS

분류:
일반차

============================================================
현재 COOKIE 튜닝샵과 역할 분리
============================================================

cookie_tuningshop:
- 속도 0~5단계
- 엔진 가속 0~5단계
- DB 저장 및 재적용

cookie_sentinelxs_handling:
- 브레이크
- 조향
- 접지
- 서스펜션
- 롤링/고속 차체 안정성
- 후륜 설정

서로 같은 값을 중복으로 건드리지 않도록 만든 구조입니다.

============================================================
현재 속도
============================================================

기존 cookie_tuningshop 패치 기준:

0단계 180km/h
1단계 188km/h
2단계 196km/h
3단계 204km/h
4단계 212km/h
5단계 220km/h

============================================================
현재 가속
============================================================

cookie_tuningshop 엔진 강화:

0단 0.245
1단 0.258
2단 0.272
3단 0.287
4단 0.303
5단 0.320

이 핸들링 리소스의 Config.OverrideAcceleration은 기본 false입니다.
기존 튜닝샵과 같이 쓸 때는 false를 유지하세요.

============================================================
설치
============================================================

추천 위치:

resources/
└─ [cookie_vehicles]/
   └─ [cookie_car_normal]/
      └─ SentinelXS/
         ├─ fxmanifest.lua
         ├─ config.lua
         └─ client.lua

Sentinel XS는 GTA 기본 차량이라
핸들링만 바꿀 때는 yft/ytd가 없어도 됩니다.

server.cfg가:
ensure [cookie_vehicles]

형태라면 분류 폴더 구조에 따라 자동 시작할 수 있습니다.

개별 시작:
refresh
ensure SentinelXS

이미 실행 중:
restart SentinelXS

============================================================
설정 바꾸는 곳
============================================================

config.lua

[브레이크]
fBrakeForce
높을수록 강함.
일반차 추천: 0.70 ~ 0.90

[조향]
fSteeringLock
높을수록 바퀴가 많이 돌아감.
일반차 추천: 34 ~ 40

[접지]
fTractionCurveMax
최대 접지력.

fTractionCurveMin
슬립 상태의 최소 접지력.

값을 너무 높이면 레이싱 게임처럼 차가 도로에 붙어버립니다.
일반차 추천:
Max 2.1 ~ 2.4
Min 1.9 ~ 2.2

[저속 미끄러짐]
fLowSpeedTractionLossMult
높을수록 저속에서 미끄러지기 쉬움.

[서스펜션]
fSuspensionForce
차체를 받치는 힘.

fSuspensionCompDamp
눌릴 때 감쇠.

fSuspensionReboundDamp
다시 올라올 때 감쇠.

[롤링]
fAntiRollBarForce
높을수록 코너에서 차체가 덜 기울어짐.

[구동]
fDriveBiasFront
0.0 = 후륜
1.0 = 전륜
0.5 = AWD

Sentinel XS는 현재 0.0 후륜으로 설정.

============================================================
인게임 확인
============================================================

센티널 XS 운전석에 탑승한 뒤:

cookie_sentinel_handling

F8 콘솔에서 실제 적용된 핸들링 값을 확인할 수 있습니다.

============================================================
로고 제거를 나중에 할 경우
============================================================

GTA 기본 Sentinel XS의 yft/ytd를 OpenIV에서 추출해서
stream 폴더에 넣으면 replacement 차량으로도 같이 관리할 수 있습니다.

그때도 이 핸들링 리소스는 그대로 사용할 수 있습니다.
